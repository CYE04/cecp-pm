# 下午聚会经文与播放器交互设计

日期：2026-09-21

## 目标

让下午聚会页面在 Halo 文章内更紧凑，同时保留经文和同步歌词的可读性。改动限定在经文展开、诗歌播放器尺寸和 Halo 嵌入占位内容，不改变每周资料格式、歌曲来源或歌谱功能。

## 经文抽拉

- “展开经文”改为一整行的清晰入口，包含经文图标、当前状态文字和方向箭头。
- 点击后，经文内容在当前位置向下顺滑展开；收起时向上合拢。页面内容自然向下移动，不使用覆盖页面的侧栏。
- 动画使用实际内容高度，加载完成后继续适应经文长度变化。快速重复点击不会卡在半开状态。
- 展开时首次读取经文，现有查阅、字号、复制、大字阅读和上下章功能保留。
- 开启“减少动态效果”时取消位移动画，直接显示或隐藏。
- 亮色和深色使用现有主题变量，焦点、键盘操作和 `aria-expanded` 状态保持可访问。

## 紧凑播放器与歌词展开

- 播放器整体高度缩至当前约 75%–80%，比最初建议的三分之二稍大。
- 保留封面、歌名、歌手、进度、播放控制、音量和当前同步歌词；减少外边距、面板间距和空白高度。
- 当前歌词至少保留两行可视空间，字号不缩到影响阅读。
- 歌词区域显示可点击提示。点击歌词后打开大歌词阅读层，显示当前歌曲的完整同步歌词；再次点击关闭按钮、背景或按 Escape 关闭。
- 大歌词层跟随当前播放进度高亮并自动滚动到当前句；播放器继续播放，不重置进度。
- 无歌词时不显示可点击状态，也不打开空阅读层。
- 手机端阅读层占大部分屏幕但保留关闭入口；桌面端使用居中的圆角阅读面板。

## Halo 嵌入

Halo 代码只保留挂载节点和脚本，不显示“打开下午聚会程序”备用链接：

```html
<div id="cecp-pm" data-date="2026-09-20"></div>
<script src="https://cye04.github.io/cecp-pm/embed.js"></script>
```

页面加载前挂载节点为空，加载失败时由脚本显示页面自身的错误提示。

## 实现边界

- 经文抽拉逻辑放在 `bible.js`，样式放在 `style.css`。
- 播放器继续由共享 `youth-engine.js` 生成；下午页面在 `songs.js` 渲染后添加紧凑样式标记和歌词阅读交互，避免改动青年页面。
- Halo 示例同步更新到 `README.md`，不修改每周 JSON。

## 异常处理

- 经文请求失败时，抽拉区域保持展开并显示原有重试按钮。
- 诗歌没有同步歌词时，播放器仍可播放，歌词区域不响应打开操作。
- 共享播放器结构变化时，增强逻辑找不到目标元素便跳过，不影响播放和歌谱。

## 验证

- 检查经文首次展开、重复展开收起、加载失败重试及减少动态效果。
- 检查播放器高度、播放进度、音量、切歌和歌谱移调不受影响。
- 检查歌词阅读层打开、关闭、Escape、背景关闭、当前句高亮与自动滚动。
- 分别检查亮色、深色、桌面宽度和手机宽度。
- 运行现有 Node 测试和 JavaScript 语法检查，并用浏览器确认无运行时错误。
